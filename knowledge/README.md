# 潮玩知识库说明

本目录用于存放潮玩设计相关的知识素材，供后端 Python Agent 在生成 prompt 或与用户沟通需求时引用。

推荐的数据组织方式：

- `toy-knowledge.json`：结构化标签与提示词模版，便于 Agent 检索。
- `materials.md`：常用材质、工艺说明以及生产限制。
- `stories/`：不同系列的世界观、角色设定文档，可被 Agent 用于扩写背景。

每份知识条目应当包含：

1. **标题**：便于检索和向用户展示。
2. **摘要**：150 字以内概述重点信息。
3. **标签**：例如「科幻」「国潮」「机甲」「透明树脂」等，用于快速过滤。
4. **关联提示词**：可直接拼装到最终 prompt 中的自然语言片段。

请在更新知识库时保持版本控制，必要时可为不同 Agent 任务创建子文件夹（如 `character-design`、`packaging` 等）。
