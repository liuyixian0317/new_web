# 潮玩知识库说明

本目录用于存放潮玩设计相关的知识素材，供后端 Python Agent 在生成 prompt 或与用户沟通需求时引用。

当前目录结构：

- `toy-knowledge.json`：涵盖潮玩风格、材质组合、特殊工艺和头身比例等维度的结构化数据，供 Agent 在决策和生成 prompt 时查询。
- `stories/`：可选的世界观、角色设定文档（未必每个项目都会使用）。

`toy-knowledge.json` 的顶层字段说明：

| 字段 | 说明 |
| --- | --- |
| `styles` | 潮玩风格的定义，包含适用场景、色彩、推荐材质与 prompt 关键词。 |
| `materials` | 常见材质与材质组合的使用场景、表面效果、prompt 关键词。 |
| `crafts` | 特殊工艺（如喷涂、热转印等），说明最佳使用场景与提示词。 |
| `headToBodyRatios` | 常用头身比例（2~5头身）的风格印象与 prompt 关键词。 |
| `pairings` | 示例搭配，用于快速组合风格、材质、工艺及头身比，并附带提示词模板。 |

维护要求：

1. 新增条目时需确保 `id` 唯一且语义清晰，便于 Agent 快速引用。
2. `promptKeywords` 和 `promptGuideline` 尽量使用英文短语，方便直接拼装或翻译。
3. 若有更多文档（如包装设计、配件清单），建议创建新的子目录并在此 README 中登记。
4. 更新知识库后请同步调整 Agent 的系统提示，确保最新规范被使用。
